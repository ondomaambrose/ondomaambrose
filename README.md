### About me

I'm a full stack developer currently strongest on the frontend, but comfortable across the
stack — from building interactive UIs to shipping the APIs that power them. I've studied
design principles alongside computer science, so I care as much about *why* an interface
looks the way it does as I do about the code behind it.

I also build **AI-integrated systems** — applications where an LLM isn't a demo bolted on
the side, but a working part of the product: routed through real APIs, wired into real
data, and shipped as a real feature.

- Computer Science student at Covenant University
- Frontend-leaning, with a working knowledge of design systems and UI/UX principles
- Comfortable building full stack — web, mobile, and desktop
- Build and ship systems with AI/LLM integrations as core functionality, not add-ons
- Currently deepening my backend skills (real-time systems, API design, databases)
- Open to internships, collabs, and interesting problems
